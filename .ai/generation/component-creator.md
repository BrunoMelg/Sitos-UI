# Component Creator

## Objective

Generate Orchard UI components following all project standards.

## Workflow

Before creating a component:

1. Read Package Architect
2. Read Token Enforcer
3. Read Accessibility Guardian
4. Read Apple Design Reviewer

## Output

Every generated component must include:

- Component
- Types
- Styles
- Tests
- Storybook
- Exports

## Required Files

Component.tsx

Component.types.ts

Component.styles.ts

Component.test.tsx

Component.stories.tsx

index.ts

## Requirements

- TypeScript
- React
- Design Tokens
- Dark Mode
- Accessibility
- Storybook
- Tree Shaking

## Default Quality Checklist

✓ Responsive

✓ Accessible

✓ Typed

✓ Tested

✓ Documented

✓ Token Based

✓ Apple Style

## Failure

If any requirement is missing, regenerate the component.
