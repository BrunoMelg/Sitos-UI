# Orchard UI Foundation

## Mission

Orchard UI is a React component ecosystem inspired by Apple's Human Interface Guidelines.

The goal is not to copy Apple interfaces.

The goal is to create components that follow the same principles:

- Clarity
- Simplicity
- Consistency
- Accessibility
- Elegance
- Performance

Every decision must favor long-term maintainability over short-term convenience.

## Core Principles

### Content First

Components must never compete with content.

### Consistency

Every component must feel like it belongs to the same system.

### Accessibility First

Accessibility is mandatory.

### Token Driven

Visual values must come from design tokens.

### Composition Over Complexity

Prefer composing simple components over creating large monolithic components.

### Premium Experience

Every interaction should feel intentional and polished.

## AI Workflow

Before creating any code:

1. Read Foundation
2. Read Architecture
3. Read Design Rules
4. Read Accessibility Rules
5. Read Component Standards

Only then generate code.
